WHY AGENTDOG 2.0

A safe response is only
part of a safe trajectory.

Agents do more than respond. They plan, call tools, change files, and carry memory across long workflows. A harmless-looking observation can quietly change what happens many steps later.

AgentDoG 2.0 connects risk characterization, adversarial evaluation, efficient guardrails, and adaptive defenses into one framework for long-horizon agent safety.

CGM

Covert goal manipulation

Subtle instructions and delayed triggers redirect the agent while the task appears to proceed normally.

AOV

Authority & obligation violations

Permissions drift, approvals become stale, and safety obligations get lost as the workflow evolves.

LoC

Loss of control

Small errors accumulate into boundary escapes, ignored stop conditions, or misleading completion reports.

    A full decision,
    in a single pass.

    Jev replaces autoregressive answer generation with structured readout at decision positions. Unified-4B reaches 77.90% unsafe F1 at 59.8 ms mean latency on ATBench.

    109.0×

    lower latency for this model pair

    Source latency figure rounds 59.8 ms to 0.060 s. Across evaluated binary variants, speedups range from 103.9× to 184.9×.

    Fine-grained diagnosis is a separate task: reported latency speedups are 4.4–13.4×, with a speed–accuracy trade-off. Binary judgment latency should not be read as end-to-end agent runtime.
